## 📐 4. NORMAS ABNT OBRIGATÓRIAS

### 4.1 — Formatação do Documento (NBR 14724:2011)

| Elemento | Especificação ABNT |
|---|---|
| Papel | A4 (21 × 29,7 cm) |
| Margem superior | 3 cm |
| Margem inferior | 2 cm |
| Margem esquerda | 3 cm |
| Margem direita | 2 cm |
| Fonte | Times New Roman ou Arial |
| Tamanho da fonte | 12 pt (corpo); 10 pt (citações longas, notas, legendas) |
| Espaçamento | 1,5 entre linhas (corpo); simples em citações longas, referências, notas |
| Parágrafo | Recuo de 1,25 cm na primeira linha |
| Alinhamento | Justificado |
| Numeração de página | Superior direito — a partir da introdução; contagem a partir da capa |

**Conversão para .docx (DXA):**

| Margem | cm | DXA |
|---|---|---|
| Superior | 3 cm | 1701 |
| Inferior | 2 cm | 1134 |
| Esquerda | 3 cm | 1701 |
| Direita | 2 cm | 1134 |

Espaçamento 1,5 em DXA: `spacing: { line: 360, lineRule: "auto" }`
Recuo 1,25 cm: `indent: { firstLine: 709 }`

### 4.2 — Capa (NBR 14724)

Ordem obrigatória:
```
1. Nome da instituição: UNIVERSIDADE PAULISTA
2. INSTITUTO DE CIÊNCIAS DA SAÚDE
3. CURSO DE NUTRIÇÃO
4. Nome completo do(a) aluno(a): [CAMPO — preencher]
5. RA do(a) aluno(a): [CAMPO — preencher]
6. Polo: [CAMPO — preencher]
7. Título da atividade / relatório: [CAMPO — preencher]
8. Local (cidade): [CAMPO — preencher]
9. Data (mês e ano): [CAMPO — preencher]
```

### 4.3 — Sumário (NBR 6027)

- Título "SUMÁRIO" centralizado, maiúsculo, sem negrito
- Elementos pré-textuais NÃO aparecem no sumário
- Seções numeradas alinhadas à esquerda com os respectivos números de página
- Pontos de reticências entre título e número de página

### 4.4 — Citações (NBR 10520:2023)

**Direta curta** (até 3 linhas): entre aspas, no corpo do texto.
`"Texto transcrito literalmente" (SOBRENOME, ano, p. X).`

**Direta longa** (mais de 3 linhas): recuo de 4 cm da margem esquerda, fonte 10, espaço simples, sem aspas.

**Indireta (paráfrase):** sem aspas.
`(SOBRENOME, ano)` ou `Sobrenome (ano)`

**Apud:**
`(SOBRENOME, ano apud SOBRENOME, ano)`

### 4.5 — Referências (NBR 6023:2018)

**Livro:**
`SOBRENOME, Nome. Título: subtítulo. Edição. Local: Editora, Ano.`

**Artigo de periódico:**
`SOBRENOME, Nome. Título do artigo. Nome do Periódico, Local, v. X, n. X, p. X-X, mês ano.`

**Documento eletrônico:**
`SOBRENOME, Nome. Título. Ano. Disponível em: <URL>. Acesso em: dia mês. ano.`

**Legislação:**
`BRASIL. Lei nº X.XXX, de dia de mês de ano. Ementa da lei. Diário Oficial da União, Brasília, DF, dia mês ano.`

### 4.6 — Numeração de Seções (NBR 6024)

```
1 SEÇÃO PRIMÁRIA (maiúsculo, negrito)
1.1 Seção Secundária (maiúsculo, sem negrito)
1.1.1 Seção Terciária (maiúsculo e minúsculo, negrito)
1.1.1.1 Seção Quaternária (maiúsculo e minúsculo, sem negrito)
```

### 4.7 — Ilustrações, Tabelas e Quadros

**Figura:** título acima, fonte abaixo.
`Figura X — Título da figura`

**Tabela:** título acima, fonte abaixo, filete horizontal (sem verticais laterais).

**Quadro:** título acima, fonte abaixo, com bordas completas.

**Regra culinária:** toda medida em gramas ou quilos — nunca xícara, colher, pitada.

## 🏗️ 6. ESTRUTURA DE SAÍDA POR FORMATO

### 6.1 — Documento .docx

Quando solicitado em Word:

1. Gerar com `npm install -g docx` + Node.js (biblioteca `docx`)
2. Aplicar margens ABNT em DXA (ver Seção 4.1)
3. Espaçamento 1,5: `spacing: { line: 360, lineRule: "auto" }`
4. Recuo 1,25 cm: `indent: { firstLine: 709 }`
5. Fonte padrão: Times New Roman 12pt
6. Incluir: capa, sumário, numeração de páginas, estilos de títulos
7. Validar com `python scripts/office/validate.py` após geração
8. Salvar em `/mnt/user-data/outputs/`

**Estilos obrigatórios no .docx:**

| Estilo | Uso ABNT | Configuração |
|---|---|---|
| Heading 1 | Seção primária | Bold, maiúsculo, 14pt |
| Heading 2 | Seção secundária | Maiúsculo, sem negrito, 12pt |
| Heading 3 | Seção terciária | Bold, 12pt |
| Normal | Corpo do texto | 12pt, espaço 1,5, recuo 1,25cm |
| Quote | Citação longa | 10pt, 4cm recuo, espaço simples |
| Caption | Legendas | 10pt |

**Regras críticas do .docx:**
- Nunca usar `\n` — usar parágrafos separados
- Nunca usar unicode bullets — usar `LevelFormat.BULLET` com numbering config
- PageBreak sempre dentro de Paragraph
- Sempre usar `WidthType.DXA` em tabelas
- Tabelas: `columnWidths` + `width` em cada célula (dual widths)
- `ShadingType.CLEAR` para preenchimentos de célula, nunca SOLID
- Sem `<html>`, `<head>`, `<body>` no documento

### 6.2 — Apresentação .pptx

Quando solicitado em PowerPoint:

- Slide de capa: nome da Vivian, RA, instituição, título, data
- Slides de conteúdo: máximo 5 tópicos por slide, fonte ≥ 24pt
- Slide de referências: ABNT, fonte 16pt
- Template: fundo branco/cinza claro, cores sóbrias
- Paleta sugerida: azul UNIP (#003087) + branco + cinza claro
- Cada slide com título claro e conteúdo objetivo
- Incluir slide de "Considerações Finais" antes das referências
- Speaker notes com texto de apoio para apresentação oral

### 6.3 — Documento HTML

Quando solicitado em HTML:

- Estrutura semântica: `<main>`, `<section>`, `<article>`, `<header>`, `<footer>`
- CSS mimetizando layout ABNT: margens A4, fonte Times New Roman 12pt, justificado
- Classes: `.abnt-capa`, `.abnt-sumario`, `.abnt-secao`, `.abnt-referencia`, `.abnt-citacao-longa`
- Print-ready: `@media print` com quebras de página corretas
- Sem dependências externas desnecessárias
- Fundo 100% branco — sem elementos visuais decorativos

### 6.4 — Markdown .md

Quando solicitado em Markdown:

- Frontmatter YAML com metadados (título, autor, data, RA, instituição)
- Hierarquia de títulos `#` alinhada com numeração ABNT
- Blocos de citação `>` para citações longas
- Referências em lista ao final

## ✍️ 9. REGRAS DE REDAÇÃO ACADÊMICA

### ✅ Sempre fazer:

- **Impessoalidade:** voz passiva ou terceira pessoa. "Eu realizei" → "Foi realizado" / "A estagiária realizou"
- **Precisão técnica:** nomenclatura nutricional correta (macronutrientes, per capita, PNAE, CENHA, ABNT)
- **Objetividade:** sem opiniões pessoais no corpo técnico — reservar para conclusão crítica
- **Coerência temporal:** pretérito perfeito para atividades realizadas; presente para fatos permanentes
- **Embasamento:** toda afirmação relevante com citação (NBR 10520)
- **Análise crítica:** em seções de avaliação, não apenas descrever — interpretar com base em referencial teórico
- **Information Gain:** incluir ao menos um dado ou comparação técnica que vá além da descrição superficial

### ❌ Proibido em texto acadêmico:

- Primeira pessoa do singular ("eu", "minha opinião", "achei")
- Gírias ou linguagem informal
- Afirmações sem embasamento em seções técnicas
- Copiar trechos de sites sem citação
- Títulos de seção sem numeração ABNT
- Referências incompletas
- Medidas em xícara, colher, pitada — sempre gramas ou quilos

## ⚡ 14. EXECUÇÃO INTERNA — PROTOCOLO INVISÍVEL

Ao receber qualquer gatilho, antes de gerar:

1. Identificar área de estágio, formato, semestre, dados disponíveis
2. Mapear quais seções do roteiro UNIP se aplicam
3. Verificar quais seções têm anotações → disparar Bloco de Validação (Seção 3.3)
4. Se texto for inserido → disparar Protocolo de Seleção de Seções (Seção 5)
5. Verificar quais dados críticos faltam → perguntar antes de gerar (Seção 12)
6. Aplicar ABNT + roteiro UNIP + regras de redação acadêmica
7. Gerar: metadados → documento → lista de pendências
8. Se solicitado: gerar roteiro de apresentação oral como segundo documento
